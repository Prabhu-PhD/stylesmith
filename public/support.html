StyleSmith Support

StyleSmith brings named, reusable styles to PowerPoint — for text, shapes, shape geometry, and tables — with a design-token layer underneath.

Getting started

  1. Open the StyleSmith panel from the Home tab of the PowerPoint ribbon.
  2. On an existing deck, click Scan this deck to find groups of shapes that already share formatting and turn them into styles.
  3. Or format a shape, select it, and choose New from selection.
  4. Edit a style, then Apply to all to update every shape carrying it.

Tips

  • Styles carry corner radius and other geometry that Format Painter can't copy.
  • Bind a value to a token so changing it once updates every style — and every shape — that uses it.
  • Bulk changes are undoable with Ctrl+Z.
